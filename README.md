# VALI MODS  PANEL

An enterprise-grade digital products reseller marketplace & gaming reseller hub UI built with modern React, Tailwind CSS, Lucide React icons, and Vite.

## Features

- **Cyberpunk Aesthetics**: High-tech neon yellow & purple glassmorphic UI card with interactive corner brackets and animated scanning laser beam.
- **Dynamic Micro-Animations**: Laser bullet particle trails, pulsing ambient lighting, dual spinning dashed rings around the logo.
- **Interactive Character Cards**: Free Fire character overlays (Hayato with sword slash effect and Kelly with muzzle flash effect).
- **Authentication Workspace**: Toggleable Sign In / Create Account tabs with styled form inputs.
- **Social Media Hub**: Instant direct links to official YouTube and WhatsApp community channels.
- **Fully Responsive Layout**: Built with mobile-first Tailwind CSS.

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/hasim2006/valimods-panel.git
   cd valimods-panel
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `https://valimods-panel-2026.vercel.app/`.

---

## Building for Production

To create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
